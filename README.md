# 🚉 ATS Alarm Analytics & Automation

## 📌 Overview
An operational data processing script designed for high-demand Railway Control Centers (GoA4). This automation tool extracts, parses, and consolidates critical system alarms and event logs generated by Automatic Train Supervision (ATS) and SCADA systems.

## 🚀 Features
* **Automated Data Parsing:** Eliminates manual data entry by automatically reading and classifying raw system logs.
* **Alarm Categorization & Counting:** Groups operational faults by frequency, severity, and system component to identify recurring bottlenecks.
* **Incident Reporting MVP:** Serves as the Minimum Viable Product (MVP) for standardizing daily operational shift reports.
* **Time Efficiency:** Reduces hours of manual log review into a task that takes seconds to execute.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Data Processing:** `pandas`, `openpyxl` / `csv` *(Nota para Bryan: ajusta si usaste otras librerías para manejar Excel/datos)*

## 💡 Engineering Value & Use Case
In critical infrastructure, incident response time is vital. Manual log reviews are prone to human error and consume valuable operational bandwidth. This script bridges the gap between raw hardware telemetry and actionable metrics, showcasing a strong Site Reliability Engineering (SRE) mindset focused on observability and automation.

> **Note:** For security and compliance reasons, all proprietary logs, IPs, and sensitive infrastructure data have been anonymized or removed from this public repository.
